# Extension packs

These packs demonstrate the assignment requirement that equivalent capabilities should be adapted to the conventions of each agent client.

## Cursor
`cursor/skill-pack.json` emphasizes workspace/project context and filesystem-oriented MCP tools.

## Gemini
`gemini/skill-pack.json` emphasizes system instructions, explicit tool declarations and structured review output.

The two packs solve related capability problems but are deliberately not identical copies.
